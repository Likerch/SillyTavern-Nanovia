# Nanovia

[English](README.en.md) | **Русский**

NanoGPT как полноценный провайдер в SillyTavern, по образцу OpenRouter: роутинг по хостам, учёт подписки и оплаты по факту, каталог моделей, расход и стоимость, мост к Maestro и остальным расширениям. Работает на ST 1.19.x.

> Статус: 0.6.0, этапы 0.1–0.6 готовы (плагин и прокси, подключения, роутинг и биллинг, каталог, аккаунт и расход, Management API, диагностика). Дальше медиа (0.7) и провайдер изображений для NAI Studio (0.8). Проверено на моке и вживую на реальном NanoGPT (запросы, стриминг, баланс, подписка).

## Панель

Вкладки: **Подключения** (форма подключения, выбор модели из каталога), **Каталог** (цены, контекст, возможности, «в подписке», хосты и подсказки по роутингу), **Маршрутизация** (все поля `provider` и что из них уводит запрос с подписки), **Ключи** (несколько ключей NanoGPT), **Управление** (Management API: ключи с лимитами, модельные пресеты), **Аккаунт** (баланс, квоты подписки, расход: реальная стоимость отдельно от эквивалента), **Диагностика** (проверки всей конфигурации с быстрыми исправлениями), **Общие**.

## Что это

**Подключение** (connection) — именованный набор: модель, роутинг, рассуждения, биллинг, кэш, поиск, память, ключ. В ST оно выглядит как обычный профиль Connection Manager, поэтому его выбирает всё: чат, Qvink, фоновые задачи Maestro, Dramatis, Localizer и Officina.

### Гибрид

Две части, расширение работает и без второй:

- **Серверный плагин** (`server/index.js`): локальный OpenAI-совместимый прокси на своём порту (по умолчанию `127.0.0.1:8787`) и админ-маршруты `/api/plugins/nanovia`. Хранит ключ NanoGPT в секретах ST, собирает запрос к NanoGPT (роутинг, рассуждения, биллинг), читает usage и стоимость, ведёт журнал.
- **Браузерное расширение** (`dist/index.js`): панель, синхронизация подключений с профилями Connection Manager, хук запросов, публичный `NANOVIA_API`, мосты к Maestro и соседям.

Режимы подключения: `plugin` (профиль смотрит на прокси), `direct` (профиль смотрит на NanoGPT, запрос собирает хук в браузере), `auto` (плагин, если отвечает, иначе напрямую). Тихого переключения нет: цена и квантизация могли бы измениться незаметно.

## Установка

Подробно, с боевым сервером и Docker, в [`docs/DEPLOY.md`](docs/DEPLOY.md).

1. **Расширение:** SillyTavern → Extensions → Install extension → `https://github.com/Likerch/SillyTavern-Nanovia`. Сборка `dist/` лежит в репозитории.
2. **Плагин (по желанию, но нужен для режима `plugin`):** скопировать `server/index.js` и `server/package.json` в `<SillyTavern>/plugins/nanovia`, это делает `scripts/install-server.ps1` (Windows) или `scripts/install-server.sh` (Linux/macOS/Docker-хост).
3. В `config.yaml` включить `enableServerPlugins: true` (или переменная `SILLYTAVERN_ENABLESERVERPLUGINS=true`) и перезапустить ST.
4. Ключ NanoGPT добавляется в секреты ST (API Connections → NanoGPT или панель Nanovia).

Порт прокси внутренний: не публиковать его наружу.

## Быстрый старт

1. Открыть панель Nanovia, добавить ключ NanoGPT.
2. Создать подключение: выбрать модель, роутинг и политику рассуждений. В Connection Manager появится профиль `Nanovia · <имя>`.
3. Выбрать этот профиль в чате или в настройках фоновых задач соседних расширений.

## Разработка

```bash
npm ci
npm run check          # типы, линтер, тесты
npm run mock           # мок NanoGPT на http://127.0.0.1:5300/api/v1
npm run build          # dist/ и server/index.js
npm run stand          # локальный ST 1.19 без Docker + мок + расширение + плагин (http://127.0.0.1:8130)
npm run stand:stop
npm run test:live      # живая проверка с настоящим NanoGPT (нужна переменная NANOVIA_LIVE_KEY, ключ нигде не сохраняется)
npm run deploy:local   # скопировать сборку в локальную ST (st-local-docker)
```

- `tools/mock-nanogpt/` — мок NanoGPT (чат со стримингом, usage и стоимость, каталог, провайдеры, баланс, подписка, Management API); описание в `tools/mock-nanogpt/README.md`.
- `tools/fixtures/` — снимок настоящего каталога (61 модель для ролёвок) и провайдеров плюс модели `mock/*`; `npm run fixtures:refresh` обновляет его с публичных адресов.
- `tools/stand/` — локальный стенд; `scripts/` — деплой и установка плагина.
- Архитектура и слои: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Контракты: `src/shared/contracts.ts`.
